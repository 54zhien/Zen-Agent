## Intent and boundaries

Composer long press arms; only subsequent upward drag lifts. Short release,
backtrack, cancellation and interruption return Full. Return preserves the existing
Pane, editor, Draft/selection/quotes/attachments and reading state. No Run command,
catalog/browse, creation, Split, Sidebar, database, dependency or build-setting change.

One presentation state owns phase/progress/operation identity. UIKit owns a single
continuous recognizer and finishing animator; the existing Surface owns its stable
hosting child. Progress never resizes that child's logical layout. Geometry remains
local; preview aspect and live Surface clipping must have continuous tested endpoints.

Eligibility explicitly combines Resting/Compact, no editing/marked text, keyboard
hidden and not transitioning, settled Composer position, no selection/quote drag,
no overlay and stable Full phase. A zero keyboard height is insufficient. Aggregate
selection by source identity; one unselected cell cannot clear another's selection.
Revalidate during drag; late animation callbacks must match their operation.

IME entry uses refusal for the current gesture, preserving all input; no queued
navigation or automatic replay after commit. This follows the upstream explicit
Editing/marked-text exclusion. The optional owner preference question remains
available; implementing this reversible default is within the continuation scope.
Record it as a ruling and review it, rather than silently queuing a stale gesture.

## Task 2: actual Surface / Composer integration

- Finalize local live-Surface-to-Current mask/transform geometry before editing host.
  Reuse uniform transform and stable untransformed content dimensions; do not stretch
  text or build a second editor. Exact geometry rejection preserves safe presentation.
- Wire a concrete presentation coordinator/view through the existing ready root and
  Pane/Composer. UIKit long press receives Resting/Compact non-control region only;
  native Editing selection and Quote drag retain priority. Return/action accessibility
  uses the same readiness and state path. Scene/viewport/keyboard changes cancel safely.
- Explicit source whitelist when this task starts: SurfaceGeometry/ConversationSurfaceHost,
  new Workspace presenter/geometry, NewConversationView, ConversationPaneView,
  ConversationComposerView, ComposerHostView/Bridge/Controller, QuoteDragBridge and
  ConversationTimelineView. No Runtime/Provider/Persistence change. Existing keyboard,
  Composer and reading assertions stay intact.
- New unit/host/real gesture UI tests must prove one editor and retained state through
  lift/reverse/return, keyboard/IME/selection refusal and long-history reading. DEBUG
  fixtures do not replace production wiring. Complete CI, independent review, merge,
  then main CI. Actual entry must follow the recorded IME refusal ruling.

## Review Focus

1. Marked text, hardware keyboard and keyboard transitions never silently commit,
   discard or enqueue navigation under a different policy from the owner ruling.
2. Armed alone stays Full; direction/backtrack, cancellation, reversal/reentry and
   late completion identity do not leave stuck or stale presentation.
3. Exactly one existing editor/Pane remains; Draft, selection and reading positions
   survive while Run ownership stays untouched.
4. Local safe area, continuous aspect-preserving mask endpoints and interrupted
   animator presentation are explicit; no global screen assumption or layout reflow.
5. Native selection/Quote/control gestures retain their behavior; Reduce Motion and
   accessibility equivalents share the same eligibility and cancellation path.

Device Gate A remains open. This plan is not a claim of measured interaction comfort.
