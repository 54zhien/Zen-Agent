## Scope and limits

Automatic formation uses local Chinese/English rules for a subset of explicit response preferences, development OS, name and main project statements. Unsupported or ambiguous phrasing is skipped. Controlled integration samples are not long-term real-user recall/precision acceptance. There is no extraction model call, vector index, or app cloud sync. Credential exclusion covers configured values and pinned shapes; arbitrary unlabeled unknown secrets cannot be universally recognized.

Original Composer/Sidebar/menu layout and animation are outside this change. The preview fixture suppresses its test-only reading-position control only during Memory UI captures. No physical-device protection, keyboard or layout acceptance is inferred from Simulator screenshots.

### Builder rulings and costs

These preserve the complete execution ledger's decisions, in their original order:

1. Use conservative local bilingual extraction without another model request. Cost: lower recall for unsupported phrasing.
2. Identify workflow-only diagnostic children separately from normal CI. Cost: focused success cannot close the stage; the unchanged full Phone/Pad gate is still required.
3. Prepare pure retrieval contracts while management CI runs, but delay runtime wiring until its native gate. Cost: provisional components can require revision; no gate order is waived.
4. Retain conservative refusal of unsupported free-form statements/languages after review. Cost: some valid memories will be skipped; the UI discloses the limitation.
5. Enforce configured credentials and pinned secret shapes without claiming universal recognition. Cost: an unknown unlabeled secret resembling an ordinary fact may escape recognition.
6. Keep approved system backup and separate physical Data Protection acceptance. Cost: no claim of recalling historical backups or proving hardware enforcement from Simulator.
7. Preserve the existing Sidebar/Search/Composer/menu scope boundary. Cost: independently tracked UI defects remain unresolved by Stage7.
8. Exclude Stage8, vectors, extraction models and app sync. Cost: bounded recall and no app-level cloud synchronization.
9. Require complete screenshot and normal native gate evidence before closure. Cost: partial diagnostics do not justify completion; physical-device acceptance remains separate.
10. Preserve the existing window-resize overlay reset and reopen the formal route during landscape QA. Cost: unsaved overlay edits retain the existing rotation-dismiss behavior.
11. Do not attribute the full-run entry miss to a permanent hitbox defect: isolated taps at the same observed center navigate. The corrective test targets the visible label after checking Agent ownership, then checks the destination after one tap. Cost: the earlier center-event cause is still unproven; this is not a product hitbox repair claim.
